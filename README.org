#+TITLE: dseams2_repro
#+AUTHOR: Rohit Goswami
#+OPTIONS: toc:nil

Snakemake + HyperQueue reproducibility package for the d-SEAMS 2.0 paper
("d-SEAMS 2.0: Incremental ring and cage algorithms for ice structure
analysis", Computer Physics Communications, submitted). Every number and
figure in the paper's benchmark and application sections comes out of this
workflow, or out of the result files it committed under =results/reference/=.

This package follows the shape of the other repro entries in this
collection (=nebmmf_repro=, =rsx_bmc_repro=): a pixi environment,
=workflow/Snakefile= with the parameter matrix in =config/=, a Slurm profile
under =profiles/=, results, and an archive tarball for deposition.

* What this reproduces

- The engine at the locked revision against its pre-2.0 baseline: neighbour
  list scaling, ring and cage pipeline, vesin overhead, thread sweep,
  hop-bound incremental updater, trajectory referee (nonzero exit on any
  ring or affiliation inequality).
- The five figshare deposits of the 2020 paper (bulk Ic, homogeneous
  nucleation, ice nanotube prisms, confined monolayer rings, in-plane RDF),
  through =require("dseams")= and through =pydseams= notebooks that assert
  their headline numbers.
- Per-frame CHILL+ and cage-membership labels with their largest clusters on
  every public nucleation trajectory of Niu, Yang and Parrinello (Materials
  Cloud 2020.0005) and on the figshare mW nucleation deposit
  (=tests/walk_compare= in the engine).
- The per-molecule accuracy sweep against CHILL+, freud (Steinhardt and
  Lechner-Dellago), OVITO PTM and the twist order parameter on labelled Ic
  and Ih lattices under Gaussian jitter and on a disordered null, with seeds
  and wall time per method.
- The specificity atlas over the GenIce polymorph library (rule
  =genice_atlas=): ice I, dense polymorphs, empty hydrate frameworks, porous
  ices and continuous random networks, ideal and under positional noise,
  labelled by the seeded cages, the cutoff cages and CHILL+.
- Cross-frontend parity of the stable workflows (CLI, Python, Lua) and a
  source manifest of every locked component.

* Sources

Everything the workflow builds is a locked component of
=config/ecosystem-lock.json=: =seams-core= (the engine under test),
=seams-base= (the baseline commit), =linkcell=, =PydSEAMSlib= and
=yodaStruct=, each at an immutable revision. =scripts/ecosystem_sources.py
fetch= clones them under =sources/=; =wire= points the front ends at the
engine; =manifest= records what ran.

* Quick start (exclusive Slurm node)

#+begin_src bash
cd dseams2_repro
scripts/elja_submit.sh prep      # login node: env, sources, wraps, data, hq
scripts/elja_submit.sh submit    # one exclusive job; hq server + snakemake
#+end_src

=prep= needs the network: it solves the pixi environment, materializes the
locked sources, downloads the Meson wraps for both engine trees, fetches the
figshare deposits (MD5-verified) and the Materials Cloud archives
(MD5-verified), and fetches the HyperQueue binary. =submit= queues one
exclusive job whose body runs the DAG through HyperQueue. Results land in
=results/=, with =results/paper_manifest.json= as the single parsed object
and =results/conditions.txt= recording node, load and revisions.

* Anywhere else

#+begin_src bash
pixi run prep          # same as above, no scheduler needed
pixi run smoke         # small matrix (config/smoke.yaml); not paper numbers
pixi run run-local     # full matrix without HyperQueue
#+end_src

Timings on a shared or loaded machine are not comparable to the paper's
exclusive-node numbers; the conditions file records the load so a reader
can tell.

* Layout

| Path | What |
|------+------|
| =workflow/Snakefile= | the DAG |
| =config/config.yaml=, =config/smoke.yaml= | sizes, repetitions, sigma grid, seeds, stride |
| =config/ecosystem-lock.json= | immutable source revisions |
| =scripts/= | source lock, fetchers, sweep, parity, aggregation, cluster drivers |
| =notebooks/= | percent-format =pydseams= notebooks (executed by the DAG) |
| =lua/= | =require("dseams")= demos |
| =data/fixtures/= | tiny fixtures for parity checks |
| =results/reference/= | committed campaign outputs the paper reads |
| =zenodo/= | deposition payload staging (=scripts/stage_zenodo.sh=) |

* Archive for Zenodo

After a full run exits 0:

#+begin_src bash
pixi run stage-zenodo
pixi run package-archive     # dseams2_repro_archive_YYYYMMDD.tar.xz + sha256
#+end_src

The record is the measurement campaign and the software at a tag. The
manuscript, cover letters and referee correspondence are not part of it.
